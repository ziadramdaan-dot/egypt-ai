# Egypt AI — نسخة مطوّرة

المشروع فيه واجهة شات عربية وسيرفر Python وعقل يمكنه استخدام أكثر من طريقة.

## تشغيل المشروع
1. ثبّت Python 3.9 أو أحدث.
2. ضع `brain.py` و`server.py` و`index.html` في مجلد واحد.
3. افتح الطرفية داخل المجلد وشغّل:
   ```bash
   python server.py
   ```
   على Windows يمكنك استخدام `py server.py`.
4. افتح `http://127.0.0.1:8000` في المتصفح.

لا تحتاج مكتبات Python إضافية.

## طرق تشغيل العقل

### الطريقة 1: Claude API + بحث الويب
- أنشئ مفتاح API من حساب Anthropic.
- احفظ المفتاح في ملف نصي اسمه `api_key.txt` داخل نفس المجلد، في سطر واحد فقط.
- أو اضبط متغير البيئة `ANTHROPIC_API_KEY`.
- يمكن تغيير اسم الموديل عبر `ANTHROPIC_MODEL`.
- استخدام API قد يتطلب رصيدًا مدفوعًا. لا تشارك مفتاحك مع أي شخص ولا ترفعه إلى GitHub.

### الطريقة 2: نموذج محلي عبر Ollama
1. ثبّت Ollama من https://ollama.com/
2. افتح الطرفية وشغّل:
   ```bash
   ollama pull llama3.2
   ```
3. تأكد أن Ollama يعمل، ثم شغّل `python server.py`.
4. لتغيير النموذج، اضبط متغير البيئة `OLLAMA_MODEL` على اسم نموذج مثبّت لديك.

النموذج المحلي يمكنه المحادثة دون إرسال الرسائل إلى خدمة خارجية، لكن جودة الرد تعتمد على النموذج وإمكانيات الجهاز. لا يعرف الأخبار الحديثة وحده إلا إذا زوّدته بأداة بحث.

### الطريقة 3: من غير مفتاح ومن غير Ollama
سيبحث المشروع عن نتائج متاحة عبر DuckDuckGo، وإذا تعذر ذلك سيحاول ويكيبيديا. هذه الطريقة تعرض نتائج وروابط، لكنها ليست بديلًا عن نموذج لغوي؛ لن تكون جودة الشرح والتركيب مثل Claude أو نموذج محلي.

## ترتيب العمل
1. ردود بسيطة للتاريخ والوقت والحساب والتحية.
2. Claude API إن كان المفتاح مضبوطًا.
3. Ollama إن كان متاحًا.
4. بحث ويب مجاني ثم ويكيبيديا.

## الملفات
- `index.html`: واجهة الشات.
- `server.py`: السيرفر المحلي.
- `brain.py`: منطق العقل وطرق الاتصال.

## ملاحظات مهمة
- لا تضع مفتاح API داخل `index.html` أو JavaScript؛ يجب أن يبقى في Python/ملف محلي.
- النسخة الحالية مخصصة للتشغيل المحلي على جهازك، وليست مجهزة للنشر العام على الإنترنت دون إضافة حماية ومصادقة وحدود للطلبات.
- معلومات البحث تحتاج مراجعة المصادر، وقد تحتوي النتائج على أخطاء أو معلومات قديمة.


## النشر على الإنترنت (Render)

- ارفع ملفات المشروع إلى مستودع GitHub خاص، ولا ترفع أي ملف مفتاح API.
- اربط المستودع بخدمة Render Web Service أو استخدم ملف render.yaml للنشر عبر Blueprint.
- لو تستخدم Claude، أضف `ANTHROPIC_API_KEY` في Environment Variables داخل Render، وليس في الكود أو GitHub. قد يتطلب استخدام API رصيدًا مدفوعًا.
- الخطة المجانية في Render قد توقف الخدمة بعد فترة من عدم الاستخدام، وقد يستغرق أول طلب بعدها وقتًا حتى تعود للعمل.
- هذه نسخة تجريبية وليست مؤمّنة بالكامل للاستخدام العام؛ لا تنشرها للعموم مع مفتاح API قبل إضافة حماية وحدود استخدام مناسبة.
